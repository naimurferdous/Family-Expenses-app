== ১. ZIP এর ভেতরে যা আছে (সবই GitHub এ তুলতে হবে) ==
www/index.html ............ পুরো অ্যাপ
www/logo.png .............. লোগো (আইকনও এখান থেকে বানানো হয়)
.github/workflows/android.yml .. বিল্ডের নির্দেশ (আইকন, সাইনিং, নিরাপত্তা সব এখানে)
debug.keystore ............ স্থায়ী সাইনিং কী (এটা থাকলে নতুন APK পুরনোটার ওপর আপডেট হয়)
capacitor.config.json, package.json

== ২. APK বানানোর ধাপ ==
1. GitHub এ Private repository খুলুন (কী ফাইল আছে, তাই Public করবেন না)।
2. ZIP আনজিপ করে সব ফাইল ও ফোল্ডার (.github সহ, debug.keystore সহ) আপলোড করুন → Commit।
   (.github না দেখা গেলে "hidden files দেখান" চালু করুন।)
3. Actions → "Build APK" → Run workflow → ৫-১০ মিনিট অপেক্ষা।
4. রানের নিচে Artifacts থেকে family-budget-apk নামান → app-debug.apk ফোনে ইনস্টল করুন।

== ৩. প্রথমবার ব্যবহার ==
1. "বাজেট" (পরিকল্পনা ট্যাব) এ আয় ও খাতভিত্তিক সীমা বসান। সব অংক ০ থেকে শুরু।
2. "আরও → নিরাপত্তা" থেকে পাসওয়ার্ড দিয়ে এনক্রিপশন চালু করুন (লম্বা পাসওয়ার্ড দিন)।
   পাসওয়ার্ড ভুললে ডেটা ফেরানোর উপায় নেই।
3. ➕ বা হোমের খাতে চেপে খরচ লিখুন।

== ৪. ফিচার ==
হোম (হাতে বাকি, পরামর্শ, বিল, সাম্প্রতিক লেনদেন, বিশ্লেষণ) | লেনদেন (তারিখ ধরে, সার্চ, Undo)
পরিকল্পনা (বাজেট, নিয়মিত বিল, সঞ্চয়, প্রজেক্টর) | আরও (ক্যালকুলেটর, নোট, শীট, ধার খাতা)
Excel/CSV/রিপোর্ট/JSON এক্সপোর্ট ও রিস্টোর | অ্যাপ সম্পর্কে

== ৫. আপডেট ও ব্যাকআপের নিয়ম ==
- নতুন বিল্ডের আগে "আরও" থেকে JSON ব্যাকআপ নিন।
- debug.keystore না বদলালে নতুন APK সরাসরি আপডেট হবে। বদলালে একবার আনইনস্টল করতে হবে।
- Excel/CSV/রিপোর্ট ফাইল এনক্রিপ্টেড নয়; কাজ শেষে মুছে দিন।

== ৬. নিরাপত্তা (বিল্ডে নিজে প্রয়োগ হয়) ==
ইন্টারনেট পারমিশন নেই | অ্যাপ ব্যাকআপ বন্ধ | ডিবাগ বন্ধ | স্ক্রিনশট/রিসেন্ট প্রিভিউ বন্ধ
AES-256 এনক্রিপশন (পাসওয়ার্ড দিলে) | ভুল পাসওয়ার্ডে ক্রমবর্ধমান অপেক্ষা
